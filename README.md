
# 🏙️ Bairro em Dia

**Bairro em Dia** é um projeto acadêmico desenvolvido com o objetivo de aproximar os cidadãos dos problemas urbanos presentes em suas comunidades.

A plataforma permite registrar e visualizar denúncias relacionadas a problemas no bairro, como ruas danificadas, iluminação pública, descarte irregular de lixo e outras situações que afetam o dia a dia da população.

## 🎯 Objetivo

Facilitar o registro de problemas urbanos por meio de uma plataforma simples, intuitiva e acessível, incentivando a participação cidadã e contribuindo para a melhoria das comunidades.

## 🚀 Funcionalidades

- Cadastro de denúncias;
- Envio de imagens;
- Registro da descrição e localização do problema;
- Visualização das denúncias em cards;
- Exclusão de registros cadastrados.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap
- localStorage

## 📚 Aprendizados

O desenvolvimento deste projeto proporcionou conhecimentos práticos sobre desenvolvimento web, manipulação do DOM, armazenamento local de dados, responsividade e organização de interfaces.

## 👩‍💻 Desenvolvimento

Projeto desenvolvido como atividade acadêmica, com foco em tecnologia, cidadania e soluções digitais para problemas do cotidiano.
